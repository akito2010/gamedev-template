# 設計
**オブジェクト**
- プレイヤー
- 敵
- 弾
- 体力表示

**オブジェクト持ってる情報**
- プレイヤー　座標(x)、移動速度、残りHP
- 敵　座標(x)、移動速度、残りHP
- 弾　移動速度、進行方向、発射間隔
- HUD　体力表示

**ゲームの状態**
- タイトル --Enterキーー＞プレイ中
- プレイ中 --Escキーー＞ポーズ中
- ポーズ中 --Escキーー＞プレイ中
- プレイ中 --HPが0ー＞ゲームオーバー
- ゲームオーバー --Enterキーー＞タイトル

**パラメータ**
- プレイヤーの速度＝150
- プレイヤーのHP＝3
- プレイヤーの弾の発射間隔＝0.1(s)
- 敵の速度＝150
- 敵のHP=30
- 敵の弾の発射間隔＝0.5(s)
- 弾の速度＝200

**設計シート**

1.登場するものとそれが持ってる情報
| オブジェクト | 情報 |
| ---- | ---- |
| プレイヤー|座標（x）、移動速度、残りHP |
| 敵|座標(x)、移動速度、残りHP |
|弾|移動速度、進行方向、発射間隔|
|HUD|体力表示|

2.状態と、移り変わる条件のリスト
| 状態 | 条件 |
| ---- | ---- |
| タイトルーー＞プレイ中|Enterキー |
|プレイ中ーー＞ポーズ中|Escキー|
|ポーズ中ーー＞プレイ中|Escキー|
|プレイ中ーー＞ゲームオーバー|HPが0|
|ゲームオーバーーー＞タイトル|Enterキー|
